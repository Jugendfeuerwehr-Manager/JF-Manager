# Jugendleiter / Bediener

Beginne mit der richtigen Abteilung. Welche Aufgaben du übernehmen kannst, ergibt sich aus deinen Rollen. Für fehlende Rechte ist die Administration zuständig.

| Aufgabe | Schrittweise Anleitung |
| --- | --- |
| Anmeldung, Orientierung, Smartphone, eigenes Profil | [Start und mobile Bedienung](start.md) |
| Aufnahme, Elternkontakte, Gruppen, Listen und Nachweise | [Mitglieder und Listen](members.md) |
| Termin dokumentieren und gemeinsam abhaken | [Dienstbuch und Anwesenheit](services.md) |
| Stationsbetrieb vorbereiten, durchführen und nachbereiten | [Übungsplanung](training.md) |
| Ausrüstung ausgeben, zurücknehmen und bestellen | [Inventar und Bestellungen](inventory.md) |
| Nachrichten verfassen und Versand kontrollieren | [E-Mail-Kommunikation](communication.md) |
| Fehlende Einträge, Konflikte oder Verbindungsprobleme | [Fehlerhilfe](help.md) |

Für einen Übungsabend: [Plan veröffentlichen](training.md#planungswarnungen-und-veroffentlichen), [Handout bereitstellen](training.md#handout), [Durchführung öffnen](training.md#durchfuhren), [Anwesenheit erfassen](services.md#jugendliche-erfassen) und danach [nachbereiten](training.md#nachbereiten).
