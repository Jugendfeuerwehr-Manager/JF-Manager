# Datenschutz (DSGVO)

Diese Seiten helfen dem Träger einer Installation, den Betrieb von JF-Manager datenschutzkonform aufzusetzen und nachzuweisen. Sie beschreiben, was die Anwendung technisch leistet, und liefern Vorlagen. **Sie sind keine Rechtsberatung.** Rechtsgrundlagen, Fristen und Texte prüft die oder der Datenschutzbeauftragte des Trägers.

## Schnellstart für eine neue Installation

1. Impressum und Datenschutzerklärung unter **Einstellungen → Datenschutz** anlegen und veröffentlichen (Vorlage: [templates/privacy-notice.md](templates/privacy-notice.md)).
2. Aufbewahrungsfristen unter **Einstellungen → Datenschutz → Aufbewahrungsfristen** prüfen.
3. Rollen nach Erforderlichkeit vergeben: Betreuer sehen keine Kontaktdaten der Kinder ([Rollen](../domains/roles-and-permissions.md)). MFA ist für alle Konten mit Zugriff auf Mitgliederdaten Pflicht.
4. Einwilligungen der Eltern (Fotos, Datenverarbeitung) einholen und beim Mitglied unter **Einwilligungen** erfassen (Vorlage: [templates/consent-form.md](templates/consent-form.md)).
5. Mit einem externen Betreiber einen Vertrag zur Auftragsverarbeitung schließen ([templates/dpa-outline.md](templates/dpa-outline.md)).
6. Verzeichnis von Verarbeitungstätigkeiten und TOM ausfüllen.
